# Changelog

## Unreleased

- feat: save system. `DataService` loads each player's save through ProfileStore 1.0.3 (vendored), migrates it on a copy to the current schema, checks it and only then lets the player in. A save from a newer build is refused untouched; a save that fails its check is kept untouched, copied to a quarantine store and the player asked to rejoin. Other services read a frozen snapshot with `get` and change data with `mutate`, which keeps a change only if the save stays valid. Session states Loading, Playing, Releasing and Ended; requests are handled only while Playing. Schema version 1 counts joins. Studio saves for real only on the Dev place with API access on (ADR 0019).
- feat: network layer. Every remote is declared in `Network/Remotes.luau` with its payload rule, rate limit and an example. `ServerNet` checks each request (shape limits, payload rule, rate limit, session) before its handler and counts strikes, kicking at 30 in a minute; `ClientNet` checks its own requests and stays under 80% of each limit. One test remote, `RequestTestPing`, answered by `TestPong`. The abuse suite is generated from the definitions and runs in the unit tests and through the real remotes at the start of every Studio playtest. New config: `Tuning.Network` and `Strings.luau` (ADR 0018).
- feat: config loader. `Config` loads `Build`, `Flags`, `Tuning` and the `Buildables` registry, checks them against `Config/Schema.luau` and deep-freezes them; a bad value stops startup with a readable message. Log levels now come from `Flags.luau` and every log line starts with the build version. New check steps: `gen-index` (registry indexes), `check-literals` (no tuning numbers in services, logic or controllers) and `validate-config` (ADR 0017).
- feat: core utilities. `Log` (tagged levelled lines), `Rng` (seeded named streams, ADR 0016), `FixedStep` and `Scheduler` (fixed 10 Hz steps, at most 5 per frame, skipped time paid by formula), with specs for frame-rate independence at 30, 60 and 144 frames per second and the catch-up cap. Both `Main` scripts now drive the Scheduler, and the server logs its session seed.
- tool: the check (`lune run check`): StyLua, Selene with the project rules, luau-lsp type analysis and Lune unit tests through the new `tools/testkit.luau`. Runs before every commit through `.githooks/pre-commit` and on every push in GitHub Actions (ADR 0015).
- docs: agent rules (`CLAUDE.md`), full README with Windows steps, decision-record template and records 0001 to 0014 for the decisions made so far.
- tool: repository scaffold (folder structure, Rojo project, pinned tools and packages, lint and format configs, Git LFS rules).
